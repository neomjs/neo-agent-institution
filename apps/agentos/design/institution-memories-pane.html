The hierarchy in one sentence: the title is the only weighted line and the recency band is the outer skeleton; kind is a closed-set chip on the T2 kind axis (EventChip's --fm-kind-* mechanism — unknown kind renders the neutral chip, never a borrowed severity); quality/impact/count stay honest mono facts (no meters — a bar would decorate what the number already says); co-authors compress to monogram marks with the full identities on title.

Provenance grammar (the two-level distinction the models already carry): summary cards wear derived (pill, quiet) — the Dream pipeline wrote them; drill rows wear authored once in the drill head — the resident wrote them. The response is the authored row's primary line (the pane's existing ruling, kept), prompt demotes to one detail line, amountToolCalls stays a micro fact.

The retrieval-hint affordance (#20's named element): an affordance-class chip per card — activating it copies the card's query_raw_memories("…") form (derived view-locally from title/session — clipboard is a view capability, no adapter change) so an operator or agent can jump from the browser into Memory Core recall. The exact query rides the button title; a card with no derivable hint renders no chip (exception logic, T2).

Implementation destination + interaction (#24 law 0 · law 1): the summary level is a custom-styled Neo.grid.Container (the primitive map names memories with the mailbox surfaces), law-1 name AgentOS.view.fleet.memories.Grid; recency bands are section rows, cards are the row design. Selection/focus/keyboard are grid-owned; the existing drill-in (open/back/more, INTENT-shaped) keeps its mechanics as row→detail — read-only throughout, nothing writes to the corpus from this surface.
